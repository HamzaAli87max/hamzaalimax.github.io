HAMZA ALI — PORTFOLIO WEBSITE
================================

Files:
- index.html
- style.css
- script.js
- assets/ (your supplied images and AI videos)

BEFORE PUBLISHING:
1. Add your chosen profile photo to assets/ and name it hamza-profile.jpg.
   The website currently has a designed initials fallback if this file is not added.
2. In index.html, replace YOUR_EMAIL@example.com with the public email address you want visitors to use.
3. Review the brand list and project labels once before publishing.

PUBLISH WITH GITHUB PAGES:
1. Create a GitHub repository named username.github.io (replace username with your GitHub username).
2. Upload all files and the assets folder to the repository root.
3. Open repository Settings > Pages.
4. Under Build and deployment, select Deploy from a branch, choose main and / (root), then Save.
5. Your site will be available at https://username.github.io after GitHub finishes deployment.

This is a static HTML/CSS/JS site. No paid hosting, database or build step is required.
